# 📖 English-Tamil Dictionary

A simple and responsive **English-Tamil Dictionary Web Application** that helps users search English words, understand their meanings, and translate them into Tamil.

## ✨ Features

- 🔍 **English Word Search** – Search for any English word.
- 📚 **Word Meanings** – Display definitions and parts of speech.
- 🌐 **Tamil Translation** – Get Tamil meanings and explanations.
- 🔊 **Pronunciation Audio** – Listen to word pronunciation.
- 📝 **Example Sentences** – Understand words through examples.
- 🔗 **Synonyms** – Discover similar words.
- 🕘 **Recent Searches** – Access recently searched words.
- ✨ **Word of the Day** – Learn a new English word every day.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- 📱 **Responsive Design** – Works on desktop and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Google Fonts

## 🔌 APIs Used

**1. Free Dictionary API**

Used to retrieve English word meanings, phonetics, definitions, examples, synonyms, and pronunciation audio.

API: https://dictionaryapi.dev/

**2. MyMemory Translation API**

Used to translate English words and explanations into Tamil.

API: https://mymemory.translated.net/

Both APIs can be used without an API key.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` using Live Server or your browser.
5. Enter an English word in the search box.
6. Click the Search button to view the results.

**Note:** An active internet connection is required to access the APIs and Google Fonts.
